# Apps for the new PC. The build downloads each one's installer (winget download) and puts it
# inside the ISO, so they install at first sign-in WITHOUT internet. Anything that fails to
# download is installed online with winget instead. Downloads are cached in <WorkDir>\downloads;
# build with -RefreshDownloads to fetch the newest versions.
# (Steam, League and Discord are small launchers: they still download the rest when first opened.)
# Find IDs with:  winget search <name>   or at https://winget.run
#
# FORMAT:  PackageID                          installs to the app's normal folder
#          PackageID | C:\Apps\Name           installs to that folder
#          PackageID | {Gaming Drive}\Games\Steam     installs on the drive whose volume LABEL is "Gaming Drive"
#          PackageID | <folder> | ask         installer has no folder switch: its window opens,
#                                             and the folder to pick is shown (and copied to the clipboard)
#
# {Gaming Drive} = your second drive. No need to prepare anything:
#   - if a drive is labelled "Gaming Drive", that one is used;
#   - otherwise the largest internal NTFS drive that isn't C: is used (USB sticks are skipped)
#     and it gets labelled "Gaming Drive" so it's recognisable later;
#   - no second drive (or it's brand new and unformatted): the app installs to its normal folder on C:.
# FirstLogon.log says which drive was picked.
#
# Optional default folder for every app WITHOUT its own path (each gets a subfolder):
# @default C:\Apps
